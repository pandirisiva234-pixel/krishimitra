# Evaluation data you need to create

These test sets must be made by you (or a fluent speaker), not generated by an AI,
otherwise the evaluation measures nothing real. Keep them small but honest.

| File | What to put in it | How many |
| --- | --- | --- |
| `stt_manifest.csv` | `audio_path,language,reference` — your recordings and the exact words spoken | 10–20 per language |
| `translation_testset.csv` | `language,source,reference_en` — a farmer question and a human English translation | 20–50 per language |
| `rag_questions.csv` | `question,language,question_en,relevant` — a question, its English version, and a phrase that must appear in the correct passage (`a|b` for alternatives) | 30–60 total |

Header-only templates are provided (`*_template.csv`). Copy them, remove `_template`, and fill them.

Tips:
- Record in the conditions farmers use: phone mic, some outdoor noise, natural speed.
- Include code-mixed speech (e.g. Telugu with English words such as "DAP", "spray").
- For RAG, write questions only after indexing your PDFs, and check the answer really is in them.
